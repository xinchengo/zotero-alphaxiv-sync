# Product Overview

## Zotero-AlphaXiv Sync Extension

This is a Zotero extension that provides bidirectional synchronization between Zotero collections and AlphaXiv folders for arXiv papers.

### Core Functionality

1. **Bidirectional Sync**: Synchronizes arXiv papers between configurable pairs of Zotero collections and AlphaXiv folders
2. **ArXiv-Only Focus**: Ignores all non-arXiv papers during synchronization
3. **Automatic Import**: Uses Zotero's "import from identifier" utility to import missing papers
4. **Configurable Pairs**: Multiple sync pairs can be configured through the preferences interface

### Key Features

- **Zotero → AlphaXiv**: Adds papers with arXiv IDs from Zotero collections to corresponding AlphaXiv folders
- **AlphaXiv → Zotero**: Imports papers from AlphaXiv folders into Zotero collections using arXiv identifiers
- **Preference Management**: Full configuration interface in Zotero's preferences section
- **Manual Sync Trigger**: Sync can be triggered via command prompt (Shift+P → "alphaXiv Sync")

### Target Users

Researchers and academics who use both Zotero for reference management and AlphaXiv for paper organization, specifically those working with arXiv preprints.
